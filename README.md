# WoW Forever: The Wanderer Challenge

**Don't level through Azeroth. Live in it.**

An immersive, zone-locked, rags-to-riches challenge for World of Warcraft: Forever, built around storytelling, professions, camping, community and character-driven play.

The site includes the complete challenge rules, interactive zone checklist, profession-based Wanderer's Network, Passage wealth progression, and unique challenges for all nine classes.

## GitHub Pages

Publish from the repository root on the `main` branch in **Settings → Pages → Build and deployment → Deploy from a branch**.

> Forever is currently in beta. Passage values and beta-specific rules are subject to balancing before release.
